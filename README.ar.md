# Tactica — غرف التحليل المشترك

موقع عربي وإنجليزي لتحليل خطط كرة القدم بشكل جماعي، بخادم Python وWebSockets حقيقي.

## التشغيل

ثبت Python 3.10 أو أحدث، ثم افتح الطرفية داخل مجلد المشروع:

```bash
python -m venv .venv
```

على Windows:

```powershell
.venv\Scripts\activate
```

على macOS أو Linux:

```bash
source .venv/bin/activate
```

ثم:

```bash
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000 --workers 1 --ws-max-size 8192
```

افتح http://localhost:8000، اكتب اسمك واترك عنوان الخادم فارغًا، واضغط **إنشاء غرفة مشتركة**. انسخ رابط الغرفة وافتحه في متصفح آخر، ثم اكتب اسم المحلل الثاني واضغط **انضمام**.

للعمل من جهازين على الشبكة نفسها، افتح عنوان الجهاز المضيف بدل localhost، مثل `http://192.168.1.10:8000`. يجب السماح بالمنفذ في جدار الحماية. للتعاون عبر الإنترنت، انشر الخادم على استضافة تدعم Python أو Docker وWebSockets.

## الاستخدام

- اسحب اللاعبين والكرة لتعديل الخطة؛ تصل التغييرات مباشرة إلى باقي المتصلين.
- اختر **سهم تكتيكي** واسحب بين نقطتين لرسم المسار.
- اختر لاعبًا واكتب اسمه واضغط حفظ.
- استخدم المحادثة للنقاش مع أعضاء الغرفة.
- زر التنزيل يحفظ الخطة بصيغة JSON؛ لا تتوفر ميزة استيراد الملف في هذا الإصدار.
- بعد انقطاع الاتصال، اضغط انضمام لاستعادة أحدث حالة.
- تحتفظ قاعدة SQLite بالخطة وآخر 100 رسالة بعد إعادة تشغيل الخادم، بشرط الحفاظ على ملف البيانات.

## ملفات GitHub

ارفع جميع ملفات المجلد بما فيها مجلد `.github` إلى مستودع جديد. راجع أوامر Git في README.md.

**GitHub Pages يشغل الواجهة فقط، ولا يشغل خادم Python.** فتح `static/index.html` يتيح التدريب المحلي. للتعاون الفعلي شغّل الخادم، أو اربط الواجهة بخادم منشور باستخدام خانة عنوان الخادم. عند فصل الواجهة والخادم، أضف أصل الواجهة إلى متغير `ALLOWED_ORIGINS` على الخادم.

## النشر والحدود

يمكن تشغيل `docker compose up --build`؛ تحفظ البيانات في وحدة تخزين دائمة. استخدم HTTPS وعملية واحدة ونسخة واحدة من الخادم. ملف DEPLOYMENT.md يحتوي إعداد Nginx مقترحًا.

رابط الغرفة يمنح صلاحية القراءة والتعديل، لذلك شاركه مع فريقك فقط. لا توجد حسابات أو أدوار أو مكالمات صوتية. عند تعديل العنصر نفسه بواسطة محللين، يعتمد آخر تعديل يصل إلى الخادم. الحد 20 محللًا لكل غرفة. للنشر العام واسع النطاق، أضف تسجيل دخول وحماية إضافية لإنشاء الغرف وبنية مزامنة موزعة.
